BALDI MOD MAKER — пакет для Unity
==================================

Что внутри (структура повторяет корень Unity-проекта игры):
  Assets/Scripts/Mod/ModRuntime.cs   — применяет настройки в игре (персонажи, моментальный подбор блокнота,
                                        музыка погони, свет/туман, главное меню, лимит времени)
  Assets/Editor/ModTools.cs           — меню «Baldi Mod» в редакторе Unity
  Assets/Resources/mod_settings.txt   — все настройки мода (ключ=значение, bind:Скрипт.поле=значение)
  Assets/Resources/mod_*.wav|mp3|ogg  — ваше аудио (музыка погони, музыка школы/меню и т.д.)
  Assets/Texture2D/...                — ваши раскрашенные спрайты по оригинальным путям (перезаписывают оригиналы)
  Assets/ModPackage/                  — map.json (школа), apk.json (название, пакет, версия), icon.png, unity_paths.json
  mod.json                            — полный проект целиком (для справки)

КАК СОБРАТЬ APK
1. Откройте проект игры в Unity 2018.3.9f1 (ProjectVersion.txt из декомпила).
2. Распакуйте этот архив В КОРЕНЬ проекта (рядом с папкой Assets), согласившись на замену файлов.
3. Unity → меню «Baldi Mod» → «1. Применить настройки APK» (название, имя пакета, версия, иконка, ориентация).
4. Откройте сцену School → «Baldi Mod» → «2. Построить школу из мода».
   Строятся полы, потолки, стены, окна, постеры, объекты, блокноты (до 100), точки появления персонажей.
   Старая школа скрывается (Environment). Затем запеките NavMesh: Window → AI → Navigation → Bake.
5. Двери (обычные, учительские, распашные) строятся как простые плоскости — чтобы они открывались,
   поставьте на их место оригинальные префабы дверей из Assets/PrefabInstance и скопируйте позиции из map.json.
   Предметы (type=item) и ИИ-точки (type=aipoint) тоже лежат в map.json — расставьте префабами Pickup.
6. File → Build Settings → Android → Build.

ВАЖНО
- Настройки с пометкой bind: меняют публичные поля оригинальных скриптов (скорость Балди, выносливость и т.д.).
- Остальные настройки читает ModRuntime. Часть настроек (правила школы, лимит жизней, поведение отдельных
  предметов) записана в mod_settings.txt, но требует доработки скриптов игры под ваши нужды.
- Спрайты в приложении сжаты до 256 px по большей стороне — при замене в Unity можно включить Filter Mode = Point.
- Скрипты не проверялись в вашей версии Unity: если будет ошибка компиляции — пришлите её, поправим.

СБОРКА БЕЗ КОМПЬЮТЕРА
Приложение Baldi Mod Maker (раздел «Сборка APK на телефоне») само отправляет этот пакет в ваш GitHub-репозиторий
с проектом игры и запускает файл .github/workflows/build-mod.yml (GameCI). Метод BaldiMod.ModTools.BuildAll
применяет настройки APK, строит школу, запекает NavMesh и собирает build/Android/mod.apk.
Нужен секрет репозитория UNITY_LICENSE (лицензия Unity Personal, файл .ulf).
